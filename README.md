# Funadansu（船箪笥）

小さな地域が、自分たちのパーソナルデータ連携基盤を持てるようにするためのソフトウェアです。
デジタル庁の推奨モジュール「パーソナルデータ連携モジュール（PxR）」と互換で、
人口千人規模の島や集落でも、国内の自前のサーバーや VPS で動かせることを目指しています。

## 名前の由来

船箪笥（ふなだんす）は、北前船の船頭が帳簿や証文、印鑑、お金を入れて船に積んだ、頑丈な箪笥です。
小さな港を寄りながら日本海と瀬戸内を結んだ北前船にとって、預かった大切なものを守る道具でした。
Funadansu は、地域から預かったデータを守り、小さな地域どうしをつなぐ基盤であることを目指して、この名前を付けました。

## なぜ作るのか

パーソナルデータ連携基盤は、これまで大きな自治体や広域での導入が中心でした。
構成が大きく、動かし続ける費用も大きいため、小さな地域では持つこと自体が難しいのが実情です。

Funadansu は、同じ仕組みを小さく、安く、国内で動かせる形に組み直します。
地域の規模にかかわらず、住民と地域の組織が自分たちの基盤を持てる状態を目指します。

## 特徴

- **PxR 互換**：公開されている API の仕様に沿って、同じ API を提供します。既存の DB はそのままに、アプリケーションだけを差し替えられます。旧来の DB から移すためのツール（移行 CLI）は今後の予定です
- **小さく動く**：サービスを1つのプログラムにまとめ、少ない計算資源で動くようにしています
- **国内で動く**：自前のサーバーや国内の VPS に置いて、データを国内で管理できます。構成は NixOS で宣言的に記述し、同じ環境を再現できます
- **認証は OIDC に対応**：既存の API の形を保ったまま、標準的な認証の方式で動きます

## 位置づけ

- スマートシティリファレンスアーキテクチャ V2 相当（2023年）の推奨モジュール（PxR）をもとにしています
- 設計は、運営者がデータを預かる **Broker 型（中央集権預かりモデル）**です。既存の基盤との互換と移行を優先した、移行期の位置づけです
- 本人がデータの鍵を持つ自己主権型の基盤は、別途開発しています

## 構成

| 部分 | 内容 |
| --- | --- |
| 入口（proxy） | TypeScript（Hono）。Cloudflare Workers で動作 |
| サービス | Go（標準ライブラリ）。1つのバイナリ |
| データベース | PostgreSQL（CockroachDB にも対応） |
| 構成管理 | NixOS、Pulumi |

## 誰が運用できるか：Do It Yourself の原則

Funadansu は、地域の組織が**自分たちの構成員で**運用することを前提にしています。

### 運用できる組織

地方公共団体、一般社団法人・一般財団法人、公益社団法人・公益財団法人、特定非営利活動法人、
認可地縁団体、法律に基づく協同組合等、法人格のない地域の団体（自治会など）。
詳しくは [ADDITIONAL-PERMISSIONS.md](ADDITIONAL-PERMISSIONS.md) を参照してください。

### 条件

- 運用は、その組織の構成員（職員、ボランティア）が自ら行ってください。運用を第三者に委託・再委託することは、許諾の対象外です。サーバーやクラウドなどの基盤サービスを借りることは、委託に当たりません
- 運用を始めるときに、[運用者の一覧](ADOPTERS.md)に登録してください
- 見つけた不具合は報告してください。脆弱性は非公開の窓口に報告してください
- 改変して運用する場合は、その改変（セキュリティの修正を含む）をこのリポジトリに戻してください

運用の費用を、税、寄付、会費、使用料などで利用者から集めることは自由です。

### なぜこの条件なのか

**1. 運用する人が、改善に参加できるようにするため**
Funadansu はソースコードを公開しています。実際に運用している人が、不具合の報告（Issue）や修正の提案を
通じて改善に参加することで、ソフトウェアは育ちます。運用を外部に任せきりにすると、
現場で起きていることが開発に返ってこなくなります。

**2. 地域に技術者が育つ場にするため**
基盤を自分たちで運用することは、地域の中に技術を持つ人が育つきっかけになります。
Funadansu は、地域ごとに小さな技術者のコミュニティが生まれ、つながっていくことを目指しています。

**3. 力ある者には責務を**
規模の大きな運用者には、Issue の対応に参加する担当者と、コミュニティへの資金の拠出をお願いしています。

### 想定される運用の形

| 運用する組織 | 置き場所 | 費用 | 運用する人 |
| --- | --- | --- | --- |
| 地縁組織・自治会 | 国内の VPS | 会費 | 地域のボランティア |
| 地方公共団体 | 自前のクラウド環境 | 予算 | 自治体の職員 |
| 地域の一般社団法人・協議会 | 法人の計算資源 | 会費・協賛金 | 法人に籍を置く職員 |

### 営利の事業者の方へ

営利法人による利用、運用、運用の支援は、個別にご相談ください。

なお、開発者（合同会社オートノミーアソシエーション）が運用する環境には、自社のサービスだけを載せています。
