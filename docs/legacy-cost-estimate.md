# 旧構成の月額の見積もり（15コンテナ、ALB、Nginx、Aurora）

フェーズ0の 8.2（[Issue #27](https://github.com/autonomy-local/funadansu/issues/27)）の記録です。移行の前後で費用を比べるための基準で、Funadansu 側の見積もりはしていません。

- 構成は、旧運用の利用設定手順書（[利用者向けの手順書](https://github.com/Personal-Data-Linkage-Module/docs/blob/develop/%E5%88%A9%E7%94%A8%E3%82%AC%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%B3/user_manual.md) の図 1‑1「AWS を使用した環境構成イメージ」）に合わせました。Internet → ALB → Nginx → EKS on Fargate（サービスコンテナ）→ Aurora、NAT ゲートウェイ、踏み台の EC2 です
- 手順書は、サーバーのスペック、インスタンスの大きさ、台数を書いていません。そこで、Pod の大きさと台数は、この見積もりのために置いた前提です（旧運用者の実際の構成とは違う可能性があります）
- 見積もりは**前提の置き方に強く依存**します。下の前提を変えれば、結果は変わります

## 結果

| 項目 | 前提 | 月額（USD） |
| --- | --- | ---: |
| EKS（クラスター料金） | 標準サポートの 1 クラスター | 73.00 |
| Fargate（vCPU） | サービスコンテナ 15 個 × 0.5 vCPU ＋ Nginx 0.25 vCPU | 286.04 |
| Fargate（メモリ） | サービスコンテナ 15 個 × 1GB ＋ Nginx 0.5GB | 62.57 |
| ALB | 1 台、LCU は常時 1 | 23.58 |
| NAT ゲートウェイ | 1 台、処理データ 10GB/月 | 45.88 |
| Aurora PostgreSQL（インスタンス） | db.r6g.large × 1 台（書き込みのみ、Single-AZ 単価） | 228.49 |
| Aurora（ストレージ） | 20GB | 2.40 |
| Aurora（I/O） | 1 か月あたり 1,000 万回 | 2.40 |
| 踏み台（EC2） | t3.micro × 1 台、gp3 8GB | 10.70 |
| **合計** | | **約 735** |

- 1 か月を 730 時間として計算しました
- Nginx は、Fargate の 1 コンテナとして数えました
- 円への換算はしていません（為替は見積もりの都度に変わるため）

### 前提を変えたときの目安

| 変えた点 | 月額（USD） |
| --- | ---: |
| Aurora に読み取り用の 1 台を足す（db.r6g.large × 2） | 約 964 |
| サービスコンテナを 0.25 vCPU・0.5GB にする（Node.js の最小） | 約 566 |

## 含めなかったもの

- データ転送（外向きの通信量）、CloudWatch などのログ、Aurora のバックアップ、Route 53、ACM
- 図 1‑1 にある ECR、CloudSearch、SNS（使用量が分からないため）
- 消費税
- 割引（Savings Plans、リザーブドインスタンス）
- 旧構成の運用の人件費

## 料金表

AWS の公開の料金表（`pricing.us-east-1.amazonaws.com` の `current/ap-northeast-1`）から、次の単価を取りました。取得日は 2026-10-11 です。

| 対象 | 料金表の日付 | 単価（USD） |
| --- | --- | --- |
| AmazonEKS | 2026-09-28 | クラスター 0.10/時 |
| AmazonECS（Fargate） | 2026-09-11 | vCPU 0.05056/時、メモリ 0.00553/GB 時 |
| AWSELB | 2026-09-11 | ALB 0.0243/時、LCU 0.008/LCU 時 |
| AmazonEC2（NAT ゲートウェイ、EC2、EBS） | 2026-10-09 | NAT 0.062/時、データ処理 0.062/GB、t3.micro 0.0136/時、gp3 0.096/GB 月 |
| AmazonRDS（Aurora PostgreSQL） | 2026-10-06 | db.r6g.large（Single-AZ）0.313/時、ストレージ 0.12/GB 月、I/O 0.24/100 万回 |

料金表は、取得日の時点の値です。料金が変わったときは、この表と結果を更新してください。

## 数えた方法

料金は、次の式で計算しました（730 時間/月）。

```
EKS      = 0.10 × 730
Fargate  = (15 × 0.5 + 0.25) × 0.05056 × 730 + (15 × 1 + 0.5) × 0.00553 × 730
ALB      = (0.0243 + 0.008) × 730
NAT      = 0.062 × 730 + 10 × 0.062
Aurora   = 0.313 × 730 + 20 × 0.12 + 10 × 0.24
踏み台   = 0.0136 × 730 + 8 × 0.096
合計     = 735.06
```

## 読み方

- この数字は、移行の前後を比べるための基準の 1 つです。移行後の Funadansu の費用は、別の見積もりで比べてください
- 小さな島や集落で動かすときの費用とは、直接には比べられません。運用者が選ぶ構成（VPS など）ごとに、別に見積もってください
