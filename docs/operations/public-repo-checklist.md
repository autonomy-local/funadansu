# 公開の前の確認（本体）

本体のリポジトリを公開する前に、置いてよいものと置かないものを確かめます（[ADR-0009](../decisions/0009-リポジトリの分離.md)、[ADR-0010](../decisions/0010-秘密情報の正本と配布.md)）。

## 置いてよいもの（本体）

| 項目 | 例 |
| --- | --- |
| コード、OpenAPI、Pulumi のプログラム、NixOS のモジュール | `bootstrap/`、`openapi/`、`deploy/example/` |
| 見本の値 | `deploy/example/.sops.yaml` の `age1example…`、`example-project-id` |
| 文書 | `docs/`、`MIGRATION.md`、ADR |

## 置かないもの（本体）

| 項目 | 置き場所 |
| --- | --- |
| 特定の環境の値（ID、ドメイン、公開鍵の実在の値） | 非公開のデプロイ用リポジトリ（`ids.md`、`Pulumi.<stack>.yaml`） |
| 暗号化した秘密情報（`secrets/`） | 非公開のデプロイ用リポジトリ |
| `.sops.yaml`（実在の宛先） | 非公開のデプロイ用リポジトリ |
| 本番の鍵、トークン、パスワード、Tunnel のトークン、R2 のアクセスキー | 運用者の環境、Secret Manager、KMS |

## 公開の前にやること

- [ ] 本体の履歴全体を、秘密情報の検出の道具（gitleaks など）で検査する。結果は、ファイルとコミットの位置だけを PR に書く（値は書かない）
- [ ] `secrets/` と `.sops.yaml` を本体から外し、非公開のデプロイ用リポジトリへ移す
- [ ] ダミー以外の値が見つかったら、作業を止めて人が判断する（履歴の書き換えは人が行う）
- [ ] `deploy/example/` の見本の値が、実在のものでないことを確かめる
